# Требования

Документ отвечает на три вопроса: чего добиваемся, что для этого должно работать и чем проверено, что оно работает.

---

## 1. Цели

| ID | Цель | Как поймём, что достигли |
|---|---|---|
| G1 | Человек не бросает занятия после первого пропуска | Пропуск не меняет ни один показатель прогресса; в интерфейсе нет механик, наказывающих за перерыв |
| G2 | Выученные слова остаются в памяти, а не забываются за неделю | Повторение назначается алгоритмически, перед моментом забывания, а не вручную |
| G3 | Человек может произнести фразу, а не только узнать её | Есть упражнения на воспроизведение, а не только на узнавание |
| G4 | Грамматика переносится в речь, а не остаётся списком правил | Каждое правило объяснено через контраст с русским и типовую ошибку |
| G5 | Понятно, с чего начинать и куда идти дальше | Есть явный маршрут с автоматической отметкой пройденного |
| G6 | Приложением можно поделиться и оно переживёт годы | Один файл без зависимостей и без сервера |

## 2. Пользователь и контекст

**Кто:** взрослый русскоговорящий, который несколько раз начинал учить английский и бросал. Читает лучше, чем воспринимает на слух. Занимается нерегулярно — два-три раза в неделю, иногда с перерывами в неделю и больше.

**Где:** телефон, чаще всего вечером, сессиями по 5–20 минут. Интернет может отсутствовать.

**Чего избегать:** любых механик, вызывающих чувство вины; жаргона, понятного только тем, кто уже в теме; интерфейса, требующего разбираться.

## 3. Функциональные требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-01 | Карточка показывает написание, транскрипцию, перевод, часть речи и пример — одновременно, на одной стороне | Обязательно |
| FR-02 | Человек оценивает своё воспоминание по четырёхбалльной шкале; оценка задаёт дату следующего показа | Обязательно |
| FR-03 | Вопрос задаётся в обе стороны: «англ → рус» и «рус → англ» | Обязательно |
| FR-04 | Слово, которое уже узнаётся, периодически спрашивается вписыванием в собственный пример | Обязательно |
| FR-05 | У глагола показываются все пять форм; неправильные берутся из таблицы, правильные строятся по правилу | Обязательно |
| FR-06 | Неправильные глаголы сгруппированы по образцу изменения; группу можно взять в повторение целиком | Обязательно |
| FR-07 | Тема грамматики содержит: суть, объяснение «почему в русском иначе», сравнение неверного и верного, типовую ловушку, примеры и тест | Обязательно |
| FR-08 | Разговорник разбит на бытовые сценарии; в каждом отдельно свои реплики и ответные | Обязательно |
| FR-09 | Любую фразу можно вывести на весь экран, чтобы показать собеседнику | Обязательно |
| FR-10 | В тексте для чтения любое слово тапается и показывает перевод с транскрипцией; словоформы приводятся к начальной форме | Обязательно |
| FR-11 | Для текста считается доля знакомых слов по фактическому словарю человека | Желательно |
| FR-12 | Слово из текста добавляется в карточки одним нажатием | Обязательно |
| FR-13 | Есть маршрут из девяти шагов; шаги отмечаются автоматически по состоянию прогресса | Обязательно |
| FR-14 | Слово с четырьмя и более промахами помечается; к нему можно записать свою ассоциацию | Желательно |
| FR-15 | Прогресс выгружается в файл и восстанавливается из файла | Обязательно |
| FR-16 | Есть поиск по словарю на английском и на русском | Желательно |
| FR-17 | Звук произносится по запросу, в обычном и замедленном темпе | Желательно |
| FR-18 | Есть экран, объясняющий механику приложения | Обязательно |
| FR-19 | Прогресс сессии можно сохранить картинкой для отправки | Опционально |

## 4. Нефункциональные требования

| ID | Требование | Обоснование |
|---|---|---|
| NFR-01 | Пропуск занятий не уменьшает ни один показатель прогресса и не меняет параметры карточек | Ядро продукта: G1. Нарушение обесценивает всё остальное |
| NFR-02 | Аудио никогда не является обязательным для прохождения любого экрана | Целевая группа воспринимает текст лучше, чем звук |
| NFR-03 | Приложение работает без интернета после первой загрузки | Занятия в дороге, в метро, за границей |
| NFR-04 | Данные не покидают устройство; внешних запросов нет | Приватность и возможность публиковать без оговорок |
| NFR-05 | Один файл, ноль зависимостей, ноль сборки | Долговечность: файл откроется через годы |
| NFR-06 | Контраст текста соответствует WCAG AA в обеих темах | Читаемость при любом освещении |
| NFR-07 | Цели нажатия не меньше 38 px | Управление одной рукой на телефоне |
| NFR-08 | Тёмная тема включается только явным выбором, не системной настройкой | Приложение задумано светлым; тёмное — опция |
| NFR-09 | Учитывается системная настройка «уменьшить движение» | Доступность |
| NFR-10 | Весь контент и все изображения — собственные | Публикация без правовых рисков |
| NFR-11 | Интерфейс обращается к человеку единообразно, на «ты» | Цельность голоса продукта |
| NFR-12 | Термины объясняются, а не называются: подпись должна быть понятна тому, кто ещё не знает темы | Целевая группа — начинающие |

## 5. Требования к учебному материалу

| ID | Требование | Проверка |
|---|---|---|
| CR-01 | Транскрипция не противоречит правилам чтения | Автоматически, 974 слова |
| CR-02 | Пример иллюстрирует именно тот перевод, который написан на карточке | Вручную, при добавлении слова |
| CR-03 | Артикли `a` и `an` выбраны по звуку, а не по букве | Автоматически, 1074 предложения |
| CR-04 | Формы неправильных глаголов соответствуют справочным | Автоматически, против эталонного списка |
| CR-05 | В тесте отмеченный ответ верен, а отвлекающие варианты действительно неверны | Вручную, все 60 вопросов |
| CR-06 | Вопросы не повторяются между темами | Автоматически |
| CR-07 | Каждое слово в текстах и разговорнике имеет перевод по тапу | Автоматически, покрытие 100% |

## 6. Границы объёма

Сознательно **не входит** в этот выпуск:

- распознавание речи и оценка произношения;
- синхронизация между устройствами и аккаунты;
- уровни выше B1;
- языки, кроме английского;
- социальные функции: рейтинги, соревнования, друзья.

Обоснование каждого пункта — в [roadmap.md](roadmap.md).

| G5, FR-13 | `pathSteps()`, `renderPath()` | «маршрут состоит из девяти шагов»; «шаг отмечается автоматически»; «номер шага совпадает с названием» |
