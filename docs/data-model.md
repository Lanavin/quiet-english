# Модель данных и потоки

Схемы написаны на Mermaid — GitHub рисует их прямо в документе.

---

## 1. Состояние приложения

Всё, что знает приложение о человеке, лежит в одном объекте `S` в `localStorage`. Учебный материал в состояние не входит: он задан в коде и одинаков у всех.

```mermaid
erDiagram
    STATE ||--o{ CARD : "cards"
    STATE ||--o{ QUIZ : "quiz"
    STATE ||--o{ READ : "read"
    STATE ||--o{ CUSTOM : "custom"
    STATE ||--o{ NOTE : "notes"
    STATE ||--o{ HIST : "hist"
    STATE ||--|| OPTS : "opts"

    STATE {
        bool seen "экран знакомства показан"
        string query "последний поиск"
    }
    CARD {
        string id PK "ключ карточки"
        float ef "коэффициент лёгкости, 1.3-3.0"
        int iv "интервал в днях"
        int reps "успешных повторений подряд"
        int lapses "промахов всего"
        date due "дата следующего показа"
    }
    QUIZ {
        string grammarId PK
        int score "верных ответов"
    }
    READ {
        string textId PK
        bool done "прочитано"
        bool ru "перевод раскрыт"
    }
    CUSTOM {
        string id PK
        string w "слово или фраза"
        string ipa
        string tr "перевод"
        string deck "custom | phrase | verb"
    }
    NOTE {
        string cardId PK
        string text "своя ассоциация"
    }
    HIST {
        date day PK
        int count "ответов за день"
    }
    OPTS {
        bool audio
        bool write "упражнение на вписывание"
        string mode "en-ru | both"
        string theme "light | dark"
        int newPerSession
        int fs "размер шрифта"
        object decks "включённые колоды"
    }
```

**Ключи карточек кодируют их тип** — это позволяет обходиться одним хранилищем для всех видов повторений:

| Вид | Ключ | Что спрашивается |
|---|---|---|
| Слово из колоды | `water` | значение или перевод |
| Слово, добавленное из текста | `curve` | то же |
| Фраза из разговорника | `p:help:2` | целиком, в обе стороны |
| Формы неправильного глагола | `v:go` | вторая и третья формы |

## 2. Жизненный цикл карточки

```mermaid
stateDiagram-v2
    [*] --> Новая: слово в колоде, ещё не показывалось
    Новая --> Учится: первый показ
    Учится --> Учится: «трудно» — интервал почти не растёт
    Учится --> Выучена: два успешных повторения подряд
    Выучена --> Выучена: интервал растёт по коэффициенту
    Выучена --> Учится: «не помню» — счётчик сброшен
    Учится --> Трудная: четыре промаха и больше
    Трудная --> Учится: записана своя ассоциация
    Трудная --> Выучена: два успешных повторения подряд
    note right of Выучена
        reps >= 2
        именно это считается
        в показателе «выучено»
    end note
    note right of Трудная
        lapses >= 4
        ещё один показ не поможет,
        нужен другой способ запомнить
    end note
```

## 3. Как оценка превращается в дату

```mermaid
flowchart TD
    A[Ответ человека] --> B{Оценка}
    B -->|Не помню| C["reps = 0, lapses + 1<br/>ef снижается на 0.20<br/>интервал = 0"]
    B -->|Трудно| D["ef снижается на 0.15<br/>интервал × 1.2"]
    B -->|Нормально| E["1-е → 1 день<br/>2-е → 3 дня<br/>дальше × ef"]
    B -->|Легко| F["ef растёт на 0.15<br/>1-е → 3 дня, дальше × ef × 1.3"]
    C --> G[Вернуть в очередь<br/>этой же сессии]
    D --> H[Дата = день ответа + интервал]
    E --> H
    F --> H
    H --> I{Проверки}
    I --> J["ef в пределах 1.3-3.0<br/>интервал не больше 365 дней"]
    J --> K[Сохранить]
    G --> K

    style G fill:#F7EAE1,stroke:#A5522F
    style H fill:#E8EFE7,stroke:#4E7055
```

Ключевая деталь на схеме — **дата считается от дня ответа, а не от плановой даты показа**. Именно это делает пропуск безнаказанным: опоздание на три месяца не меняет ни интервал, ни коэффициент лёгкости.

## 4. Сборка сессии

```mermaid
flowchart LR
    A[Открыть сессию] --> B[Взять просроченные<br/>due меньше или равно сегодня]
    A --> C[Взять новые<br/>лимит из настроек]
    B --> D[Перемешать]
    D --> E[Собрать очередь:<br/>три повторения, затем одно новое]
    C --> E
    E --> F{Ограничение<br/>по количеству?}
    F -->|Режим «пять карточек»| G[Обрезать до пяти]
    F -->|Обычный| H[Полная очередь]
    G --> I[Показ]
    H --> I
```

Чередование «три повторения — одно новое» не даёт сессии превратиться в сплошной поток незнакомого: новое перемежается тем, что уже узнаётся.

## 5. Какой стороной спрашивать

```mermaid
flowchart TD
    A[Карточка на показе] --> B{Тип}
    B -->|формы глагола| C[Начальная форма →<br/>вторая и третья]
    B -->|фраза| D[В обе стороны<br/>по чётности повторений]
    B -->|слово| E{Сколько<br/>повторений?}
    E -->|меньше двух| F[Англ → рус:<br/>сначала узнавание]
    E -->|два и больше| G{Каждое<br/>третье?}
    G -->|да| H[Вписать слово<br/>в свой пример]
    G -->|нет| I{Чётность<br/>повторений}
    I -->|чётное| F
    I -->|нечётное| J[Рус → англ:<br/>активное вспоминание]

    style H fill:#F7EAE1,stroke:#A5522F
```

Логика в том, что навыки разные и включаются по очереди: сначала узнать, потом вспомнить, потом достать из памяти и написать самой.

## 6. Разбор слова при тапе в тексте

```mermaid
flowchart TD
    A["Тап по слову, например «minutes»"] --> B[Привести к возможным начальным формам]
    B --> C["minutes → minute<br/>went → go (по таблице)<br/>studies → study<br/>slower → slow"]
    C --> D{Искать по порядку}
    D --> E[Глоссарий этого текста]
    D --> F[Словарь приложения]
    D --> G[Служебные слова]
    E --> H[Показать перевод,<br/>транскрипцию и пометку<br/>«форма слова …»]
    F --> H
    G --> H
    H --> I{Слово уже<br/>в карточках?}
    I -->|нет| J[Кнопка «в карточки»]
    I -->|да| K["Пометка «уже в карточках»"]
```

Приведение к начальной форме — не косметика: без него половина слов в тексте осталась бы без перевода, потому что в живом тексте слова стоят в изменённых формах.

## 8. Учебный материал в коде

Материал отделён от состояния и от логики — это позволяет проверять его отдельными скриптами.

| Структура | Что содержит | Объём |
|---|---|---|
| `DECKS` | Колоды слов: слово, транскрипция, перевод, часть речи, пример, перевод примера | 673 слова в 9 колодах |
| `IRREG` | Неправильные глаголы по группам образцов изменения | 76 глаголов в 7 группах |
| `GRAMMAR` | Темы: суть, «почему», сравнение, ловушка, примеры, тест | 20 тем, 60 вопросов |
| `TRIPS` | Сценарии разговорника: свои реплики и ответные | 27 сцен, 215 фраз |
| `TEXTS` | Тексты с построчным переводом и глоссарием | 12 текстов |
| `SOUNDS` | Звуки: схемы, шаги, ловушка, минимальные пары | 8 звуков |
| `COMMON` | Служебные слова и сокращения для разбора по тапу | ~300 записей |
| `BASIC` | Слова, считающиеся знакомыми при оценке сложности текста | ~130 слов |
