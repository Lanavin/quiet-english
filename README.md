# Quiet English

Приложение для изучения английского, построенное вокруг одной идеи: **обучение не должно давить**. Здесь нет счётчика дней подряд, нет сердечек и нет наград за регулярность — пропуск ничего не сжигает и не откатывает назад.

Один HTML-файл. Без сервера, без аккаунтов, без сборки. Открывается двойным кликом, ставится на домашний экран телефона, работает офлайн. Все данные остаются на устройстве.

## Зачем это сделано

Формулировка проблемы, с которой всё началось, дословно: *«всю жизнь учила и не выучила»*.

За этим стоит не лень и не отсутствие способностей, а три конкретных сбоя, каждый из которых поддаётся исправлению:

| Что происходит | Почему это происходит | Что сделано в ответ |
|---|---|---|
| Занятия бросаются через неделю-две | Механики удержания построены на тревоге: пропустил день — счётчик сгорел — смысл продолжать пропал | Расписание повторений привязано к датам, а не к непрерывности. Пропуск не наказывается ничем |
| Слова учатся и забываются | Повторение идёт вразнобой, а не в момент, когда память вот-вот отпустит слово | Интервальный алгоритм SM-2: каждое слово имеет свой счёт и возвращается перед забыванием |
| Правила выучены, но речь не собирается | Грамматика подаётся как набор правил без причин, поэтому не переносится в живую фразу | Каждая тема начинается с ответа на вопрос «почему в русском иначе», а не с формулировки правила |

## Что внутри

| Раздел | Объём |
|---|---|
| Словарь | 673 слова в порядке частотности, с транскрипцией, переводом, частью речи и примером |
| Грамматика | 20 тем с объяснением «почему», разбором типовой ошибки и тестом из трёх вопросов |
| Формы глаголов | 76 неправильных глаголов, сгруппированных по образцу изменения; правило для правильных |
| Разговорник | 27 бытовых сценариев для поездки: 126 своих реплик и 89 ответных |
| Произношение | 8 звуков, которых нет в русском, со схемами положения языка и вида рта |
| Чтение | 12 текстов уровней A1–B1 с тапом по любому слову и оценкой доли знакомой лексики |

## Ключевые решения

Подробно — в [docs/decisions.md](docs/decisions.md). Коротко:

- **Нет счётчика дней подряд.** Он мотивирует не учиться, а не терять цифру, и именно он выключает людей после первого пропуска. Отказ от него — не упущение, а позиция продукта.
- **Чтение как основной канал.** Аудио есть везде, но оно опционально и никогда не блокирует прогресс.
- **Никакого бэкенда.** Данные лежат в браузере. Это даёт офлайн, приватность и нулевую стоимость владения, но исключает синхронизацию между устройствами — осознанный размен.
- **Один файл без зависимостей.** Пять лет спустя он откроется так же, как сегодня. Ни одна сборка этого не гарантирует.
- **Весь контент свой.** Иллюстрации нарисованы в SVG внутри файла, чужих изображений нет — приложение можно публиковать и показывать без оговорок.

## Как запустить

Открыть `index.html` в браузере. Всё.

На iPhone: открыть в Safari → «Поделиться» → «На экран "Домой"». Дальше запускается как обычное приложение и работает без интернета. На Android то же самое в Chrome.

## Тесты

```bash
cd tests
npm install jsdom
node run.js
```

138 проверок: алгоритм повторений, целостность данных, английский материал, прогон интерфейса. Рядом лежат отдельные проверки:

| Скрипт | Что проверяет |
|---|---|
| `run.js` | Всё вместе, основной прогон |
| `check-english.js` | Транскрипции против правил чтения, артикли по звуку, формы глаголов против эталона |
| `check-ru.js` | Русские тексты: пунктуация, склейки, единство обращения |
| `check-ipa.js` | Допустимость знаков IPA, ударения, долгота гласных |
| `audit.js` | Пустые состояния, обе темы, цели нажатия, доступность |
| `build-preview.js` | Собирает `preview.html` — все экраны на одной странице |

Тесты написаны так, чтобы при поломке называть конкретное место по-русски.
